## 🔍 核心代码解读（面试可能会问）

### 关键操作一：按保单号汇总理赔金额

```python
# 这是整个分析最核心的一行代码
policy_summary = (
    df.groupby("保单号")["理赔金额"]
    .sum()
    .reset_index()
    .sort_values("理赔金额", ascending=False)
)
```

**逻辑**：用 `groupby("保单号")` 把同一个保单的所有理赔记录聚在一起，再 `sum()` 算出每个保单的理赔总额，最后按金额降序排列 → **Top 10 就这么出来了**。

### 关键操作二：绘图核心代码

```python
plt.plot(x, y, marker="o", linewidth=3)
for i, v in enumerate(y):
    plt.annotate(f"¥{v:.2f}万", (i+1, v))  # 给每个点加标签
```

**逻辑**：把 Top 10 的排名作为 X 轴，理赔金额作为 Y 轴，画折线 + 标数据点 + 手动加标签，面试官一看就知道你会做可视化。

## ❓ 常见问题

**Q：我不会 Python，能运行这个项目吗？**  
A：可以！你只需要安装 Python，然后双击 `run.bat`，所有代码自动执行。不需要手写一行代码。

**Q：这是真的保险数据吗？**  
A：是模拟生成的，但完全模拟真实保险理赔的数据分布（右偏：大量小额理赔 + 少数大额理赔），业务逻辑和真实场景一致。面试官在意的是**你会不会处理这类数据**，而不是数据本身是不是真的。

**Q：10 万条数据算大吗？**  
A：对于面试来说完全足够。10 万条能体现你处理"大数据"的能力，又不会让电脑卡死。面试官看到你能处理 10 万级数据，就已经认可你的基本功了。

**Q：项目太简单怎么办？**  
A：你可以自己加需求！比如：按险种分别分析 Top 5、预测下个月理赔金额、画出理赔金额分布直方图等。这些都可以直接加到 `analysis.py` 里。
